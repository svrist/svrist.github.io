This Privacy Policy explains how this website ("the site") handles information.
The site is a static, informational page hosted on GitHub Pages. It is used to
provide information about, and links to, `rclone` configuration and related
tooling.

## Information we collect

The site does not collect, store, or process any personal information. It does
not use cookies, analytics, advertising, or any other tracking technology, and
it does not ask you to create an account or submit any data.

## Hosting and server logs

The site is hosted by GitHub Pages. As with any web host, GitHub may
automatically collect limited technical information (such as IP addresses,
browser type, and request timestamps) in its server logs in order to operate
and secure the service. This processing is carried out by GitHub, not by the
site owner, and is described in the
[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

## Third-party applications

This site does not run any application and does not have access to your data.
If you choose to use `rclone` or another client with an account you control
(for example a cloud storage provider), any access to your data happens
directly between you and that provider, under the terms and privacy policy of
that provider, and only after you explicitly grant authorization. Credentials
created during such authorization are stored by you (locally or wherever you
choose) and are never sent to this site.

## Children's privacy

This site is not directed at children and does not knowingly collect
information from anyone.

## Changes to this policy

This policy may be updated from time to time. Any changes will be posted on
this page with an updated date below.
